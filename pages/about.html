About this collection

Every route on this site comes from one file: pages.json. A route is either local (an HTML file in this repository) or external (an HTML page that lives somewhere else, such as a Claude artifact). Astro turns the registry into static pages; GitHub Pages serves them.

Local pages

Point a route at a file. A fragment like this one is rendered through Astro's Doc layout, so you can write plain HTML without boilerplate. A file that is already a full document is served byte for byte instead.

{
  "route": "/about",
  "type": "local",
  "file": "pages/about.html"
}

External pages

External routes have three modes.

ModeWhat the visitor getsSurvives the source going away?
importA snapshot of the source HTML, served from this domainYes
embedThe live source inside an iframeNo
redirectAn immediate jump to the source URLNo

import is the default, and the right choice for Claude artifacts: an artifact is a self-contained HTML file, so copying it here loses nothing and frees the route from anyone else's hosting.

{
  "route": "/claude-demo",
  "type": "external",
  "mode": "import",
  "url": "https://claude.site/artifacts/..."
}

Two render paths

A complete HTML document cannot be nested inside an Astro layout — you would get html/head/body inside html/head/body, which browsers silently restructure. So imported snapshots and local full documents are written straight into public/ and copied verbatim into the build. Fragments and the embed/redirect shims go through Astro properly.

Adding a page

node tools/add.mjs --route /claude-demo --url https://claude.site/artifacts/... --title "Claude demo"
npm run dev

The snapshot lands in imported/ and is committed alongside the code, so a deploy never depends on the source being reachable.
