HTML basics

A sample local page, registered at the multi-segment route /notes/html-basics. It builds to site/notes/html-basics/index.html, which GitHub Pages serves as a clean URL with no .html in it.

Document skeleton

<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Page title</title>
  </head>
  <body>
    <h1>Hello</h1>
  </body>
</html>

Fragment or document?

This file is a fragment: no <html>, no <head>. The build detects that and wraps it. Write a full document instead whenever you want complete control over the page's styling.

Replace this file with your own notes, or delete the route from pages.json.
